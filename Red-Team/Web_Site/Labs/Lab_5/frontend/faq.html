FAQ

Common questions for checkout, promotions, and returns.

How are returns reimbursed?

Eligible return requests are reimbursed based on the original catalog list price of the purchased product.

Are there handling or administrative deductions?

No. Approved returns are credited without administrative deduction.

When is refund value credited?

Credits are added to the customer wallet balance once a return is approved.

What is MEGA80?

MEGA80 is a legacy system identifier in our database. Customers who know this code can reference it during checkout for special order tracking purposes. Limited to 5 uses per account.
